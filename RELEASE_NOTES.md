
# Student Task Manager
# Release Notes

## Version 1.0.0

**Release Date:** 24 November 2026

### New Features
- User Signup functionality.
- User Login functionality.
- Add new academic tasks.
- Delete existing tasks.
- Mark tasks as completed.
- Dashboard showing total, completed, and pending tasks.
- Responsive user interface.

### Bug Fixes
- Added validation for empty login fields.
- Added validation for empty signup fields.
- Prevented empty task submission.
- Implemented task deletion.
- Implemented task completion.

### Known Issues
- Authentication is a frontend demonstration and is not secure for production use.
- Passwords are stored in browser localStorage.
- No server-side authentication is implemented.
- Tasks are stored in browser localStorage rather than a cloud database.
- Data is specific to the browser and device.
